# @magicblock-labs/hyperpay-types

Shared types, errors, and amount helpers. No I/O, no Solana client. Safe in the browser.

```ts
import { toBaseUnits, formatAmount, PolicyError } from '@magicblock-labs/hyperpay-types'
import { parseMoney } from '@magicblock-labs/hyperpay-types/amounts'
```
